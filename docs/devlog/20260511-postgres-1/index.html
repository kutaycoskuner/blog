Studying database through postgres project

To address my knowledge gaps regarding databases, I decided to start a PostgreSQL project. I had previously built a project using Supabase, but my server was deactivated after 90 days of inactivity. During this learning phase, I was looking for a more permanent and always-accessible solution.

I initially installed it locally on my computer, but this restricted my ability to access the database from external networks.

Ultimately, I found the solution by creating a “clone” on my Raspberry Pi.

To set this up, I started by creating a Docker image via Portainer.

Here is the stack I used for PostgreSQL and the pgAdmin web interface:

version: "3.9"

services:
  postgres:
    image: postgres:17
    container_name: postgres-core
    restart: unless-stopped

    environment:
      POSTGRES_USER: appuser
      POSTGRES_PASSWORD: strong_password_change_me
      POSTGRES_DB: appdb
      PGDATA: /var/lib/postgresql/data/pgdata

    volumes:
      - postgres_data:/var/lib/postgresql/data

    ports:
      - "5432:5432"

    networks:
      - db_network

  pgadmin:
    image: dpage/pgadmin4
    container_name: pgadmin-core
    restart: unless-stopped

    environment:
      PGADMIN_DEFAULT_EMAIL: admin@example.com
      PGADMIN_DEFAULT_PASSWORD: strong_admin_password

    ports:
      - "5050:80"

    networks:
      - db_network

volumes:
  postgres_data:

networks:
  db_network:

Normally, passwords should be hidden using environment variables or secrets, but for now, I’m skipping that to focus on one problem at a time. Since the connection is routed through Tailscale, only I can access it. In other words, the database is not exposed to the public internet.

After creating the stack on Portainer, I first checked if pgAdmin was running:

http://<tailscale_ip_for_pi>:<port_for_pgadmin>


pgadmin web interface

The pgAdmin interface is working perfectly.

Next, I connected to my Pi via SSH and established a connection point through the terminal:

# create database terminal
docker exec -it postgres-core psql -U appuser -d appdb
    # output: appdb#

# connection info check
\conninfo
    # output: You are connected to database "appdb" as user "appuser" via socket in "/var/run/postgresql" at 

# check list of databases
\l
    # output: list of databases


access to database from terminal

Everything looks good. Postgres is running as a Docker container. Finally, I connected to the database through the pgAdmin interface in my browser to serve as a double-check mechanism.

Now, I will build a project I’ve wanted to do for a long time: a database that groups and evaluates fitness exercises (of which I had previously created a prototype).

The schema will be shaped around interconnected data such as exercises, step-by-step instructions, required equipment, difficulty levels, alternative movements, and target muscle groups.

I’ll start by creating the project-specific database, named kareldb, through the Postgres entry point in the terminal.

# create database
create database kareldb;

\c kareldb
    # expected to see kareldb#

# create user table for testing
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username TEXT NOT NULL UNIQUE,
    password TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT NOW()
    );


# check if table is created
\dt

# insert value
insert into users (username, password)
      values('user', 'pass');

# check if its inserted properly
SELECT * FROM users;


access to kareldb

Great! We have successfully created our first database, table, and data entry. I verified these same steps via pgAdmin by navigating through:

servers > ... > daabases > ... > schemas > public > tables

Finally, I initialized the database using an SQL template I had modeled previously. You can see the constant values and table relationships below:

-- ---------------------------------------------------------------------------------------
-- Create other tables
-- ---------------------------------------------------------------------------------------

CREATE TABLE IF NOT EXISTS difficulty_levels (
  id SERIAL PRIMARY KEY,
  name VARCHAR(50) UNIQUE NOT NULL,
  description TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS equipments (
  id SERIAL PRIMARY KEY,
  name VARCHAR(50) UNIQUE NOT NULL,
  description TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS exercise_types (
  id SERIAL PRIMARY KEY,
  name VARCHAR(50) UNIQUE NOT NULL,
  description TEXT NOT NULL
);

-- ---------------------------------------------------------------------------------------
-- Related tables
-- ---------------------------------------------------------------------------------------

CREATE TABLE IF NOT EXISTS exercises (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  description TEXT,
  level_id INTEGER REFERENCES difficulty_levels(id),
  equipment_id INTEGER REFERENCES equipments(id)
);

CREATE TABLE IF NOT EXISTS tags (
  id SERIAL PRIMARY KEY,
  name VARCHAR(50) UNIQUE NOT NULL
);

CREATE TABLE IF NOT EXISTS exercise_tags (
  exercise_id INTEGER NOT NULL REFERENCES exercises(id) ON DELETE CASCADE,
  tag_id INTEGER NOT NULL REFERENCES tags(id) ON DELETE CASCADE,
  PRIMARY KEY (exercise_id, tag_id)
);

CREATE TABLE IF NOT EXISTS exercise_muscle_groups (
  exercise_id INTEGER NOT NULL REFERENCES exercises(id) ON DELETE CASCADE,
  muscle_id INTEGER NOT NULL REFERENCES muscles(id) ON DELETE CASCADE,
  type VARCHAR(20) NOT NULL CHECK (type IN ('primary', 'secondary')),
  PRIMARY KEY (exercise_id, muscle_id, type)
);

CREATE TABLE IF NOT EXISTS progressions (
  id SERIAL PRIMARY KEY,
  exercise_id INTEGER NOT NULL REFERENCES exercises(id) ON DELETE CASCADE,
  name VARCHAR(100) NOT NULL,
  level_id INTEGER REFERENCES difficulty_levels(id),
  description TEXT
);

CREATE TABLE IF NOT EXISTS how_to_steps (
  id SERIAL PRIMARY KEY,
  progression_id INTEGER NOT NULL REFERENCES progressions(id) ON DELETE CASCADE,
  step_number INTEGER NOT NULL,
  instruction TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS media (
  id SERIAL PRIMARY KEY,
  progression_id INTEGER NOT NULL REFERENCES progressions(id) ON DELETE CASCADE,
  type VARCHAR(20) NOT NULL CHECK (type IN ('gif', 'video', 'image')),
  url TEXT NOT NULL
);
