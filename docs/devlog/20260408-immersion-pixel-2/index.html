Devlog: Light Interactions

In the next step of building my 3D pixel scene, I expanded the grass meadow implementation and focused on improving lighting and share texture data of terrain to the grass.

  1. Lighting reference setup First, added some simple geometry with a basic material and a moving point light. This helped me establish a reference to verify that the lighting behaves correctly.

  2. Custom shader lighting Next, passed the light data as uniforms into my custom shader so I could calculate lighting directly in the grass shader.

  3. Terrain-driven color variation Created a height texture to generate color variation across the terrain. The grass patches sample this same data so their color and lighting blend naturally with the ground.

  4. Wind animation Finally, I added a soft wind effect by slightly moving the upper vertices of each grass quad using a time based sinus wave.

Next steps The next feature I want to implement is pixelization and color quantization to achieve a more stylized look.

I believe the state now reached where it’s somewhat presentable, so I’ve put up a live example. I’d be happy to hear any suggestions or feedback.

Try it here: https://kutaycoskuner.github.io/immersion/pixel
